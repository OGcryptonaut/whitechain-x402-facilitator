# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The full text at that link applies to every project space: the GitHub repository, issues, pull requests, discussions, and any chat or call organised for the project.

## In short

We want this to be a project where people can ask a beginner question about x402 or Whitechain and get a useful answer, and where a disagreement about a design is about the design.

Expected:

- Be respectful and assume good faith.
- Give and accept technical criticism plainly, with reasons.
- Keep discussion on the work: the code, the protocol, the documentation.
- Credit other people's work.

Not acceptable:

- Harassment, insults, or personal attacks of any kind.
- Sexualised language or imagery, or unwelcome advances.
- Publishing someone's private information without their explicit permission.
- Sustained disruption of issues, reviews, or discussions.
- Promoting scams, token sales, or unrelated commercial offers in project spaces.

## Reporting

Report a problem privately to the maintainer, Sahil Massey ([@OGcryptonaut](https://github.com/OGcryptonaut)):

- use the contact details on the maintainer's GitHub profile, or
- use GitHub's **Report content** option on the comment, issue, or pull request concerned.

Include links or screenshots where you can. Reports are kept confidential. Please do not open a public issue to report a conduct problem.

Security vulnerabilities are handled separately; follow [SECURITY.md](SECURITY.md) for those.

## Enforcement

The maintainer reviews every report and decides on a response in line with the Contributor Covenant enforcement guidelines: a private correction, a warning, a temporary ban, or a permanent ban from project spaces, depending on severity and repetition.
